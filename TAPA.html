T.A.P.A.Technologia Aestimationis Pignorium Absentium

T.A.P.A. is an experimental neural network architecture based on NNUE, designed for potential integration into future versions of the MissingPawn chess engine.

The project explores an alternative way of representing chess positions by separating pawn structure, individual pieces, and king position. Its main goal is to reduce redundant feature encoding, improve computational efficiency, and develop a compact evaluation network without sacrificing the information needed for accurate chess position evaluation.

Key Objectives

Custom Feature Representation

Experimenting with a specialized representation of pawn structures, pieces, and king positions.

Efficient Incremental Updates

Updating evaluation data after moves instead of recomputing everything from scratch.

Performance Optimization

Reducing unnecessary computations, memory usage, and model complexity.

Neural Network Training

Developing a trainable model with verifiable evaluation quality.

MissingPawn Integration

Building a foundation for future integration and performance benchmarking.

Current Status

T.A.P.A. is an ongoing experimental project. Its repository contains an initial implementation skeleton, but the target architecture, complete training pipeline, and reliable evaluation model still require further development and testing.

The project takes inspiration from the evaluation architecture of MissingPawn v3, exploring a different approach to neural network-based chess evaluation.
