About the project

What is MissingPawn?

MissingPawn is an actively developed chess engine created by Kacper Wieczorek, also known as Missing Player. The project is written in C++ and uses CMake and the Universal Chess Interface (UCI) standard, allowing it to work with software that supports chess engines.

The main goal of MissingPawn is to experiment with different ways for a chess engine to make decisions. The project includes experiments with search algorithms, position evaluation, and tactical play. Particular attention is given to pawns — their movement, pawn structures, and their impact on the evaluation of a position.

The engine contains the core components required for independent chess play: board representation, move generation and validation, position search, position evaluation, UCI support, and opening-book support.

MissingPawn does not have a completely fixed architecture. Its structure and algorithms evolve between versions, as experimenting with new ideas and testing their impact on the engine's play is an important part of the project.

The project is open-source.
