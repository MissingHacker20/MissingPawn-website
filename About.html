About the project

What is MissingPawn?

MissingPawn is an open-source chess engine written in C++ and intended for use with software supporting the UCI protocol.

The project is being developed experimentally. It focuses on move search, position evaluation, tactical and positional play, and pawn structure analysis. The current version available for download is v2.

Engine tests

Rating results and number of games played should be interpreted solely based on current CCRL or CCI data. We do not provide unverified ratings on the site.

The experimental approach to pawn play describes the project's goal and research area, not a confirmed advantage over other engines.

Main areas

  • Move search and generation
  • Position evaluation and scoring
  • Pawn structure analysis
  • Tactical and positional experiments
