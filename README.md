# MissingPawn Website
Official website of the [MissingPawn](https://github.com/MissingHacker20/MissingPawn) project — open-source UCI chess engine written in C++.

**Strona:** https://missinghacker20.github.io/MissingPawn-website/

The website provides information about the engine, links to the source code and download releases, as well as links to external services.
